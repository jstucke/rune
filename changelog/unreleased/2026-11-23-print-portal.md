- `Tx::prepare_print` shows the desktop's print dialog and answers with the reader's settings, page setup and pages (`PrintPrepared`); `Tx::print_pdf` then hands the app's PDF to the print service (`PrintSent`). On Linux this is the XDG desktop portal's Print interface, modal over the window on X11 and Wayland; a desktop without it answers `NoService`, other platforms `Unavailable`. Tests answer both steps with `Runtime::resolve_print_dialog` and `Runtime::resolve_print_job`. A missing portal's error reply now reads as unavailable in the file dialog too.
