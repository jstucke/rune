- `App::on_close_request` lets an app keep its window open when the user asks to close it (its close button or the window manager's close): the hook runs before the window hides or `on_close` runs, and returning false keeps it shown with what the hook changed drawn, so an editor can ask "Save changes?" first. `Tx::close_window`, `AppHandle::close`, quitting and macOS Quit close without asking. Scripts send a close request with `{"close": true}`.
